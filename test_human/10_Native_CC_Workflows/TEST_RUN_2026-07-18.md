## Defects filed
- **AIHUB-0056 (major, competency/UX):** (a) the plain-English build requires excessive clarification
  rounds — the native Database node has no connection-enumeration or schema-discovery tool, so the agent
  repeatedly asks the user for the connection id, join keys, columns, and re-confirmation even for a
  clear request; and (b) after such a multi-turn clarification build, the terse follow-up "run it"
  **loses the visual_workflow continuity marker and delegates to the builder** (no native run, no output
  file). Honest throughout (no fabrication), but the headline "bread and butter" build→run flow is
  broken end-to-end for a normal user. (In a clean one-turn build, continuity holds — AIHUB-0055 — so
  the continuity break is downstream of the clarification loop.)
