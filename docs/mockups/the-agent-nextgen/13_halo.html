Reports for James: lead with the number, then the table. Currency to the dollar, no cents. Always note the as-of time. Vendors keep their legal name on first mention, short name after. Percent changes get a sign and one decimal at most. If a figure is estimated or partial, say so on the same line — never in a footnote.
